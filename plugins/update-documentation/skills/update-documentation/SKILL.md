  out of the main context. Use when asked to update, refresh, sync, audit, or
  check the docs, after a substantive change that may have left them stale,
  or when asked whether the README or CLAUDE.md is still accurate, even if
  the word "documentation" never appears.

# Update Documentation

Launch a subagent to give the documentation in README.md, CLAUDE.md, and anywhere
else in the repo a thorough review and ensure they're up-to-date with the rest of the
repository, have all the relevant context a human and AI would require, and are free
of any stale info.
